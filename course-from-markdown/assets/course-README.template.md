## How this course works

This is a self-paced, fill-in-the-blank course. Every lesson has a short reading and a few exercises. The exercises live in real source files with `# TODO:` markers — you write code, the tutor runs the tests, you iterate.

To learn from this course, run Claude Code in this directory and ask it to teach you:

```
cd <this-directory>
claude
> start lesson 1
```

The course-from-markdown skill installed on your machine reads `_TEACHER.md` and walks you through one exercise at a time. When you're ready to check your work, say "check my exercise" — Claude runs the tests and gives you a hint if you're stuck.

Reference solutions live in each lesson's hidden `.solutions/` directory. Don't read them. The tutor uses them to ground hints; you'll only see one if you explicitly ask "show me the answer".
